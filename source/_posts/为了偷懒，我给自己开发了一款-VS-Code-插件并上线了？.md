### 背景：VS Code写文档的插入图片问题

Obsidian 在笔记圈可谓是小有名气，但我依然选择在万能的 VS Code 中以 Markdown 格式来做笔记、写作业等。首先它足够轻量且全能，安装插件后可支持 Latex 公式、Mermaid 图表、预览分离且热更新、导出为 PDF、甚至 AI 自动补全，基本覆盖了我的所有场景；其次关于归类的问题，部分较为完善的笔记已上传至个人博客由标签和类别分类，而本地的以文件夹分类对我个人来说也足够方便；最后是每写下一部分内容即可 `ctrl + `` 快捷打开终端推送到远程仓库，安全感满满。

![alt-text](/img/VScodeExtentions1.png)

但其中令我比较不爽的是插入图片的存储问题。当然可以通过配置 VS Code 的 markdown.copyFiles.destination，让粘贴的图片统一保存到指定文件夹，但即使只多出一个文件夹对我这种极简主义也如鲠在喉。因此每次写文档时非必要不直接插图片，图片内容能转 Markdown 表格或者 Mermaid 图表的就都先转换再写入。这样还有另一方面的好处：不仅让排版更干净，阅读体验也更连贯。

但图片转文本的过程也涉及到要向 AI 客户端粘贴图片进行提问，再等待结果，再复制结果，最后到相应位置进行粘贴。虽然也不是很耗时，但就是少了点极致的方便，于是我突然萌生出一个想法：自己开发一个解决这个应用场景的  VS Code 插件。

### 关于开发体验和插件本身

![alt-text](/img/VScodeExtentions2.png)

换做以往做这类开发，多半要先啃官方文档的硬骨头，但有了 AI 的加持让学习成本极度压缩。从安装脚手架（不用人工找），到脚手架结构分析（知道怎么用），再到核心功能的编码（解决实际问题），都通过 AI 光速上手。就好比在游戏里要干掉一个BOSS，AI 能给你找来最锋利的剑，再告诉你这个剑怎么用，最终 BOSS 怎么打。

但我也没有放任 AI 自由发挥，即使目前我还不会写 JS，但至少能读懂和考虑优化。

最开始 AI 推荐使用传统的 OCR（光学字符识别）API 来处理文字识别提取，但编码繁杂且实测效果非常不好。所以又立刻想到不如改用视觉大模型的 API，开箱即用，且额度充足。

另一方面是 AI 给的实现方案居然将秘钥直接硬编码进代码中，即使初衷也只是本地使用，但潜在的安全性问题摆在那令人极度不适，而且后续如果想更换 API 也异常麻烦。

后面再经过一番折腾也很快就把这个插件弄出来了，甚至实际上修改说明文档、设计绘制插件 Logo 所用的时间还远大于开发核心功能的时间。插件功能也确实单一，但至少完美解决了我的实际需求。并且自定义性很高，启动快捷键和默认提示词都可以修改。

### 最后谈一点个人感悟

首先是对于万能的 VS Code，插件开发极为方便，且个人开发的本地插件也能正常使用，不得不佩服其高度自定义化的强大。

但更想谈的还是关于 AI 。本次开发并未给我带来 AI 在编码能力上的震撼，这种震撼在大一的暑期课程 “Web 开发” 的课程项目中就感受到了：在前后端、数据库几乎零基础的情况下，靠 “提需求 -> AI 生成 -> 人工审阅 -> 现学现用 -> 反思优化” 的方式，搓出了一个像模像样的全栈项目。

而这次插件开发让我体会更深的，是“想法落地” 的极致缩短。利用 AI 可以跳过许多繁琐的技术门槛，让产品快速成型甚至上线，这也许也是最近很火的 “一人公司（OPC）” 概念的一缕缩影吧。

那么软件技术正在被 AI 平权稀疏？看起来是的，就如这次开发的这个功能简单的插件、或一个静态网页，普通人借助 AI 也能生成。但再往深的走，当项目规模大、技术栈交织、业务逻辑复杂时，AI 也开始捉襟见肘。我也试过在 Vibe Coding 中，只是不断地向 AI 叠加需求，项目很快就会变成一座难以维护的屎山，AI 也束手无策。

AI 确实实现了软件领域的平权，但平权的是应用门槛，不是技术本身。面对复杂项目仍需人工理解需求，设计架构，做安全性、可扩展性的兜底。不过这也是目前的情况，未来如何也无法预料，但也许无论如何人能产生好的想法才是最重要的。

那么还是那个问题：程序员会被 AI 取代吗？首先工具不能替代人，但 AI 对生产效率的提升太显著了，会用 AI 的程序员一定可以替代不会用 AI 的程序员，因此给程序员提出了更高的要求。而另一方面，AI 不能承担责任，出事了还得让人来背锅。

既然又说到了安全性问题，不得不再喷这次 AI 给的把 API Key 硬编码的方案，如果没有人工审查一不小心开源泄露了，分分钟直接一夜破产。这也联想到了前段时间有点类似 “淘金热” 的 “养虾热”，OpenClaw 执行力的惊艳来源于用户给的超高权限，但也有着潜在的极大风险。

那如果把这看成一笔交易：为了换取更高的效率，你又愿意冒多大的风险、掏出多少权限交付给 AI 呢？
