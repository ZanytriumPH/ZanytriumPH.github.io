    开站之篇👋

    2025-11-12 07:54:44 更新于 2026-08-07 16:17:52 约 710 字 预计阅读 3 分钟 本文访问量 0 其他 碎碎念

    写在最前面

    首先感谢我 “亦友亦师” 的高中同学 Ferne（Github，博客，微信公众号），为我提供了这个基于 Hexo 使用 Github Pages 快速搭建个人博客的 idea，我的博客由此诞生。

    为什么要搭建博客？

    • 首先我喜欢尝试新鲜事物，搭建博客是我从未涉足的领域，而且开始前预想这个过程和结果均会很有意思（事实也如此）。

    • 其次对外来说这也算是我与外界联系的一个平台，希望我的博客内容能给读者带来一定的收获。

    • 最后对自己而言，这可以是一个适合我的文本阅读器，也可以是一个感悟发布地、产出记录者、任务计划表等，也许一定程度上能够促进自我的 “良性循环”。

    我会在这里发布什么？

    • 学习笔记、心得体会、生活感悟等。

    这个博客是怎么搭建的？

    并非从 0 到 1 的搭建，尽管这是我最初的想法，但出于对时间成本的考虑，我选择借助开源的力量。

    如果你也想省时省力地搭建一个属于自己的博客（并且完全免费！），可以参考以下步骤：

    这里推荐要有一定的编程基础

    1. 前备知识

    核心逻辑：用 Hexo（框架）把 Markdown 文章生成静态 HTML 页面 → 用 Git（工具）把静态文件推送到 GitHub 仓库 → 用 GitHub Pages（服务）托管这些文件，生成可访问的博客网址。

    各工具的作用：Node.js 跑 Hexo，VS Code 写文章 / 改配置，Git 同步 GitHub 上的代码

    语言
    • Markdown：一种轻量级标记语言，用来写文章
    • YAML：一种数据序列化格式，用来配置博客
    工具
    • VS Code：个人比较推荐的一个轻量级但功能强大的源代码编辑器
    • Node.js：一个基于 Chrome V8 引擎的 JavaScript 运行环境，用来运行 Hexo
    • Git：分布式版本控制系统，这里用来推送至 Github、管理博客的版本等
    平台
    • Github：一个代码托管平台，用来存放博客源码、部署博客等
    • Github Pages：Github 提供的静态网站托管服务，用来部署博客
    • Hexo：一个快速、简洁且高效的博客框架，用来生成博客静态页面

    2. 准备工作

    1. 安装代码编辑器 VS Code，并安装相关插件（如 Markdown、Git 等）
    2. 配置 Node.js 环境
    3. 安装并配置 Git
    4. 注册 Github 账号，这个网站可能比较不稳定，有时候可能需要一定 “魔法” 才能正常访问

    3. 搭建博客

    1. 点击前备知识的 Github Pages 链接，查看其官方文档，按步骤操作
    2. 点击前备知识的 Hexo 链接，查看其官方文档，按步骤操作

    Have a nice day !
